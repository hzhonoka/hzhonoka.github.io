这是一篇放在**技术**板块的示例文章，演示学习笔记长什么样。把它换成你自己的内容吧。

## 笔记怎么写比较好用

给自己和学弟学妹看的笔记，最重要的是**说人话**：

- 先写"这个知识点是干嘛的"，再写细节
- 踩过的坑值得单独记一笔，比正确结论更有价值
- 代码示例要能直接跑，贴半截代码最折磨读者

## 代码块示例

```cpp
#include <iostream>

int main() {
    // 笔记里的代码最好带注释
    std::cout << "写给后来的人\n";
    return 0;
}
```

## 给学弟学妹留资料

想放课件、PDF、往年卷之类的文件给大家下载：

1. 把文件传到仓库的 `assets/files/` 文件夹（GitHub 网页直接拖进去就行）
2. 文章里这样写链接：

```markdown
[点击下载：某某资料.pdf](assets/files/某某资料.pdf)
```

单个文件别超过 25MB（网页上传的限制），特别大的文件建议放网盘然后贴链接。

> 记笔记的意义：三个月后回来看，能救自己一命。
