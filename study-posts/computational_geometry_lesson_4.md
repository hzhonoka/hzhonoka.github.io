## 4.2 鞋带公式

只要按顺序给出多边形的顶点，套公式就能直接算出面积！

> 对于按**顺时针**或**逆时针**顺序给出的多边形顶点$(x_1,y_1),(x_2,y_2),...,(x_n,y_n)$:
> 
> 面积 = $\frac{1}{2}|\sum\limits_{i=1}^{n}(x_i\cdot y_{i+1}-x_{i+1}\cdot y_i)|$
>
> 其中$(x_{i+1},y_{i+1})$ = $(x_1,y_1)$

为什么叫这个可爱的名字？

```
    x1   x2   x3   x4
y1  ·----·----·----·
    |\   |\   |\   |
    | \  | \  | \  |
y2  ·----·----·----·
    |  \ |  \ |  \ |
    |   \|   \|   \|
y3  ·----·----·----·
```

大概就是这种交叉相乘的样子很像鞋带啦，不对这个是题外话

代码实现：

```cpp
double polygonArea(vector<Point>& p) {
    int n = p.size();
    double ans = 0;
    for (int i = 0; i < n; i++)
    {
        int j = (i + 1) % n;  // 下一个顶点，最后一个连回第一个
        ans += p[i].x * p[j].y - p[j].x * p[i].y;
    }
    return fabs(ans) / 2.0;
}
```

## 4.3 有向面积

如果我们把上面式子的绝对值扒掉，那么类比我们前几课学过的三角形面积，那么我们不难得出此时的结果表示的是有向面积~

| 有向面积  | 顶点顺序          |
| ----- | ------------- |
| `> 0` | 逆时针（数学标准坐标系）  |
| `< 0` | 顺时针           |
| `= 0` | 所有点共线，不是合法多边形 |

虽然说我们直觉上肯定经常使用绝对值计算，但是有向面积还是会在之后用到的，所以提一下~

## 4.4 多边形和点的关系

我们在之前做过了三角形和点的关系计算，那么我们在多边形之中应该如何研究它呢？

### 思路

从点 P 向右引一条射线，统计这条射线与多边形边相交的次数：

- 奇数次 → 点在内部
- 偶数次 → 点在外部

emmm，乍一看似乎能意会到其合理性，更严谨的来讲，这是 **Jordan 曲线定理** 的直接应用：
一条从 $P$ 出发、延伸到无穷远的射线，每穿过多边形边界一次，就从“内部”切换到“外部”或反之。而无穷远点一定在外部。

但是如果我们好巧不巧引了一条穿过顶点的射线，那么在内的点穿过多边形一个角，和多边形两条边交点，岂不是错掉了……

**解决方案**：统一规则——只计算"向下"的边（或只计算"向上"的边）。

```cpp
bool inPolygon(vector<Point>& p, Point q) {
    int n = p.size();
    bool c = false;  // 交叉次数奇偶性
    
    for (int i = 0, j = n - 1; i < n; j = i++) {
        // 如果点刚好在边上，直接返回 true
        if (onSegment(p[i], p[j], q)) return true;
        
        // 边 p[i]-p[j] 是否与向右的射线相交
        // 只统计"跨越"q.y 的边，避免顶点重复计数
        if ((p[i].y > q.y) != (p[j].y > q.y)) {
            // 计算交点的 x 坐标
            double x = (double)(p[j].x - p[i].x) * (q.y - p[i].y) 
                       / (p[j].y - p[i].y) + p[i].x;
            if (x > q.x) c = !c;  // 翻转奇偶性
        }
    }
    return c;
}
```

开玩笑的，秉持着认真的态度我们还是要把$(y_i>p_y)\not =(y_j>p_y)$ && $p_x<x_i+\frac{(x_j-x_i)(p_y-y_i)}{y_j-y_i}$这一判断条件的理由解释清楚的

重复计数穿过顶点有两种情况

### 局部极值顶点 两侧同侧
```
   U       W
    \     /
     \   /
       V        V.y = p_y
```

此时$U_y>p_y$且$W_y>p_y$（或同时小于），射线在$V$处只是擦过多边形，并没有真正穿进去。真实交点贡献应该是 0 或 2（偶数），不能是 1。

### 单调穿过顶点 两侧异侧
```
   U
    \
     \
      V        V.y = p_y
     /
    /
   W
```

此时$U_y>p_y>W_y$（或反之），射线在$V$处真正穿过边界，真实交点贡献应该是1。

所以规则必须做到：

- 局部极值顶点：贡献0或2（偶数）；

- 单调穿过顶点：贡献恰好1。

### 三种朴素区间规则为什么只有半开区间能用

把每条边 $A\to B$ 在 $y$ 方向看成一个区间 $[\min(y_A,y_B),\ \max(y_A,y_B)]$，判断 $p_y$ 是否落在这个区间里。

#### 规则 1：闭区间 $[y_{\min},y_{\max}]$

顶点 $V.y=p_y$ 同时属于两条边的闭区间。

| 顶点类型 | 两条边计数 | 结果 | 正确吗 |
|---|---:|---:|---|
| 单调穿过 | $1+1=2$ | 偶数 | ❌ 应为 1 |
| 局部极值 | $1+1=2$ | 偶数 | ✅ 应为偶数 |

单调穿过被多算了一次。

#### 规则 2：开区间 $(y_{\min},y_{\max})$

顶点 $V.y=p_y$ 不属于任何一条边的开区间。

| 顶点类型 | 两条边计数 | 结果 | 正确吗 |
|---|---:|---:|---|
| 单调穿过 | $0+0=0$ | 偶数 | ❌ 应为 1 |
| 局部极值 | $0+0=0$ | 偶数 | ✅ 应为偶数 |

单调穿过被漏掉了。

#### 规则 3：半开区间 $[y_{\min},y_{\max})$

统一规定：**下端闭、上端开**。顶点 $V$ 如果恰好等于 $p_y$，就把它当成“不高于射线”的下端点。

| 顶点类型 | 两条边计数 | 结果 | 正确吗 |
|---|---:|---:|---|
| 单调穿过 | 上端边不计 + 下端边计 = $0+1=1$ | 奇数 | ✅ |
| 局部最低（两侧在上方） | 两条边都以下端身份出现 = $1+1=2$ | 偶数 | ✅ |
| 局部最高（两侧在下方） | 两条边都以上端身份出现 = $0+0=0$ | 偶数 | ✅ |

只有半开区间能在所有情况下都给出正确的奇偶性

### 条件 $(y_i>p_y)\ne(y_j>p_y)$ 是半开区间

设 $a=y_i,\ b=y_j$。条件

$
(a>p_y)\ \ne\ (b>p_y)
$

表示“$a,b$ 中恰有一个严格大于 $p_y$”，等价于：

$
\min(a,b)\ \le\ p_y\ <\ \max(a,b)
$

也就是 $p_y$ 落在半开区间 $[y_{\min},y_{\max})$ 内。

### 交点横坐标公式的推导

边 $A(x_i,y_i)\to B(x_j,y_j)$ 的参数方程：

$
\begin{cases}
x(t)=x_i+t(x_j-x_i)\\
y(t)=y_i+t(y_j-y_i)
\end{cases}
,\quad t\in[0,1]
$

令 $y(t)=p_y$：

$
p_y=y_i+t(y_j-y_i)
\;\Longrightarrow\;
t=\frac{p_y-y_i}{y_j-y_i}
$

代回 $x(t)$：

$
x_{\text{intersect}}
=x_i+\frac{(x_j-x_i)(p_y-y_i)}{y_j-y_i}
$

### 为什么用 $p_x<x_{\text{intersect}}$

射线是向右的，只统计 $x\ge p_x$ 那部分。交点必须严格在 $P$的右边才计数：

$
p_x<x_{\text{intersect}}
$

啊嘞，为什么用严格小于而不是 $\le$？

因为如果 $x_{\text{intersect}}=p_x，说明交点正好是$P$本身，即$P$落在边上。这种情况应该在**边界判断**里被捕获的说，不会走到射线计数。所以这里用严格小于即可~

总之到这里大概就能解释上面的一坨程序代码在干什么啦）

所以多边形的有向面积 = $\frac{1}{2}\sum\limits_{i=1}^{n}(x_i\cdot y_{i+1}-x_{i+1}\cdot y_i)$

如下

设多边形内部区域为 $D$，边界为 $\partial D$。若顶点按逆时针排列，由格林公式，
$
\iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dx\,dy
=\oint_{\partial D}P\,dx+Q\,dy.
$
取
$
P=-\frac y2,\qquad Q=\frac x2,
$
则
$
\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}
=\frac12-\left(-\frac12\right)=1.
$
于是
$
A=\iint_D 1\,dx\,dy
=\frac12\oint_{\partial D}(x\,dy-y\,dx).
$

现在逐条边计算。第 $i$ 条边从 $P_i$ 到 $P_{i+1}$，参数化为
$
x=x_i+t(x_{i+1}-x_i),\qquad
y=y_i+t(y_{i+1}-y_i),\qquad 0\le t\le 1.
$
于是

$
dx=(x_{i+1}-x_i)dt,\qquad
dy=(y_{i+1}-y_i)dt.
$

代入：
$
\begin{aligned}
\int_{P_iP_{i+1}}(x\,dy-y\,dx)
&=\int_0^1\Big[(x_i+t\Delta x)\Delta y
-(y_i+t\Delta y)\Delta x\Big]dt\\
&=x_i\Delta y-y_i\Delta x,
\end{aligned}
$
其中

$\Delta x=x_{i+1}-x_i,\qquad \Delta y=y_{i+1}-y_i.$
中间含 $t$的项正好抵消：
$t\Delta x\Delta y-t\Delta y\Delta x=0.$

所以
$\int_{P_iP_{i+1}}(x\,dy-y\,dx)
=x_i(y_{i+1}-y_i)-y_i(x_{i+1}-x_i)
=x_i y_{i+1}-x_{i+1}y_i.$
对 $i=1,\dots,n$求和，得

$A=\frac12\sum_{i=1}^n(x_i y_{i+1}-x_{i+1}y_i).$
这是逆时针时的面积。若顶点是顺时针排列，格林公式右边整体变号，得到 $-A$。因此统一写成

$A=\frac12\left|\sum_{i=1}^n(x_i y_{i+1}-x_{i+1}y_i)\right|.$
