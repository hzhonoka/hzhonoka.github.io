给自己看的备忘录，写文章的常用语法都记在这儿。

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 文字

**加粗** 用两个星号包起来，*斜体* 用一个星号，`行内代码` 用反引号。

## 列表

- 前面加短横线
- 就是无序列表

1. 前面加数字
2. 就是有序列表

## 引用

> 前面加一个大于号，
> 就是引用块。适合放歌词和诗。

## 代码块

```python
def mint():
    return "🌱"
```

## 图片和链接

```markdown
![图片说明](assets/photos/xxx.jpg)
[链接文字](https://example.com)
```

写完记得去 `data/posts.js` 里登记，不然不会出现在列表里哦。
